# Sophia Thermal

Controle de temperatura embarcado utilizando ESP32.

## Objetivos

- Leitura de temperatura com DS18B20
- Máquina de Estados
- Controle ON/OFF
- Simulação de relé através de LED
- Evolução futura para SSR

## Hardware

- ESP32
- DS18B20
- LED
- Resistor 4k7
- Resistor 220R
